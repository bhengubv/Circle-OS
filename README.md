# Circle OS

A privacy-first Android distribution. You're NOT the product.

Circle OS is a GSI — it replaces the system partition and leaves the phone's
own firmware alone. One image, any phone that can take it.

**Alpha.** Read [what does not work](docs/reference/limitations.md) before you
install anything.
